### portfolio-tee
- Definition：Internal codename of Temitope Williams's personal portfolio website built with Next.js App Router, used as the repository name and npm package name.

### Temitope Williams
- Definition：The portfolio owner — product designer and project manager whose work, services, and contact form are showcased on the site.

### featuredProjects
- Definition：The top-level set of 4 projects displayed prominently on the Work section, distinguished from the 3 additional projects hidden behind the 'View All' toggle in `Work.tsx`.

### additionalProjects
- Definition：A secondary set of 3 projects gated behind the 'View All' button in the Work section, separate from the always-visible featured set.

### light box
- Definition：Full-screen image viewer nested inside `ProjectModal` supporting zoom levels (1x / 1.5x / 2x), thumbnail strip navigation, and keyboard controls for browsing project images.
- Aliases：lightbox
