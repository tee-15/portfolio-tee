The module is a flat Next.js App Router `app/` directory. `layout.tsx` is the root layout exporting `Metadata`, `Viewport`, and three Google Fonts (Outfit, Geist Mono, Dancing Script) injected as CSS variables; it also sets Open Graph/Twitter card metadata and re-exports `robots.ts`/`sitemap.ts` at the app root for SEO. `page.tsx` is the sole client entry (`"use client"`) that defines four inline section components (`AboutSection`, `ServicesSection`, `PlaygroundSection`, `ContactSection`) plus a footer, and composes top-level UI: `GlobalEffects`, `CustomCursor`, `Navigation`, `Hero`, `Work`, and a `ContactModal` whose open state is held in `Home` via `useState`. Visual primitives live in `components/Decorations.tsx` (`GlowOrb`, `FloatingRing`, `FloatingDot`, `FloatingPlus`, `SectionNumber`, `DottedGrid`, `CornerBrackets`, `DiagonalLine`) and are reused by every section to build a consistent parallax background. Mouse-driven parallax is centralized in `hooks/useMouseParallax.ts`, which exposes a container hook (`useMouseParallax`) returning a ref + normalized mouse MotionValues and a value-only hook (`useMouseParallaxValue`) that derives spring-animated `x`/`y` offsets from shared MotionValues; sections bind the container hook to their `<section>` and pass the resulting values into decoration components. Accessibility is handled by `hooks/useReducedMotion.ts`, a `useSyncExternalStore` wrapper around `window.matchMedia('(prefers-reduced-motion: reduce)')` that avoids SSR hydration mismatches. External configuration (EmailJS service/template/public keys and recipient email) is isolated in `config/emailjs.ts` as `as const` exports consumed by `ContactModal`.
