Next.js App Router with per-page client rendering (`"use client"`), Framer Motion (`useMotionValue`, `useSpring`, `useTransform`) for spring-based parallax and scroll-triggered animations, Tailwind CSS with custom design tokens (accent colors, surface/background), Lucide React icons, EmailJS browser SDK for contact form delivery, and `next/font/google` for Outfit, Geist Mono, and Dancing Script.
