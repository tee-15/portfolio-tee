Flat Next.js project rooted at the workspace root with all source under `app/`; there are no separate child packages or services, so cross-child orchestration does not apply. The app is bootstrapped by top-level configuration files (`next.config.ts`, `tsconfig.json` with `@/*` path alias, `eslint.config.mjs`, `postcss.config.mjs`) consumed uniformly by every page and component, making the single deployable unit self-contained.
