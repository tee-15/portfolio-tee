Built as a Next.js App Router application under `app/`. `layout.tsx` is the root layout that injects Google fonts (Outfit, Geist Mono, Dancing Script), global CSS, viewport/metadata, and Open Graph/Twitter cards. `page.tsx` is the client entry (`"use client"`) composing top-level UI: `GlobalEffects`, `CustomCursor`, `Navigation`, `Hero`, `Work`, and three inline section components (`AboutSection`, `ServicesSection`, `ContactSection`) plus a footer; it owns the `ContactModal` open state via React `useState`. Reusable visual primitives live in `components/Decorations.tsx` (GlowOrb, FloatingRing, FloatingDot, FloatingPlus, SectionNumber, DottedGrid, CornerBrackets, DiagonalLine) and are reused across every section to create a consistent parallax background. Interaction logic is extracted into `hooks/useMouseParallax.ts`, which exposes both a container hook (`useMouseParallax`) that tracks mouse position relative to a ref and a value hook (`useMouseParallaxValue`) that derives spring-animated x/y offsets from shared MotionValues; `hooks/useReducedMotion.ts` gates motion for accessibility. External configuration is isolated in `config/emailjs.ts` (EmailJS service/template/public key constants). SEO metadata is centralized in `layout.tsx` with dedicated `robots.ts` and `sitemap.ts` files at the app root.
