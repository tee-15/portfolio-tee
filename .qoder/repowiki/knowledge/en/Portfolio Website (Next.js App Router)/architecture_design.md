The repository is a flat Next.js App Router project rooted at the workspace root; all source lives under `app/` and is bootstrapped by `next.config.ts`, `tsconfig.json` (with `@/*` path alias), and `package.json` scripts (`dev`, `build`, `start`, `lint`). There are no separate child packages or services — the app itself is the single deployable unit, so cross-child orchestration does not apply. Configuration is centralized in top-level config files (Next, TypeScript, ESLint, PostCSS/Tailwind v4) consumed uniformly by every page/component.
